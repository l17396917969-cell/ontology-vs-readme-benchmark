# 新风险发现 · 受控实验

测试用已知对象和关系，发现资料里没有写明的隐患。所有组都没有逐题模板、风险函数、金标或分析示例。请求只给审查对象，不提示风险类型。试验不检验模型能否发明从未见过的风险概念。

- 三种不同结构：看似两套货源共用一个加工点、复产动作的前置条件成环、发起人与审批代理最终同属一方。每种三个世界，只改一个关键关系或其可用性，分别应得有风险、在给定范围内未见风险、资料不足。
- 两档目录规模。同一个问题、事实和答案，加相似资产干扰，保持查询范围内的源记录不变。
- 三个调用组：读整份 Markdown；对同一份 Markdown 按词排名只取前十块；按对象编号从同一套关系索引走最多四跳并取至多十块。全文为充足预算对照。两个局部组拿到的都是同款 Markdown 原文，变化只有选文档方式。
- 另做 README 链接解析对照，读取 Markdown 底层编号链接，验证在同一跳数与预算下，选文及发给模型的提示可逐字相同。它不增加模型调用，证明带链接的 README 可以提供等价的图入口。问题明给 ID，编号解析完全相同。
- 逐题独立调用同一模型两次。要求风险与证据回执。金标同时判结论类型、真实影响对象及最小有效证据。风险描述另可人工对看。正例的路径列出真实证据 ID；危害和原因需要由模型合成。负例和缺失例相邻世界共同通过才记一次稳定区分。
